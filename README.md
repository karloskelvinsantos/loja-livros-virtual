# Loja de Livros Virtual

Este é um projeto de estudo para o desenvolvimento de uma loja de livros virtual.

## Objetivo

Explorar conceitos de desenvolvimento backend utilizando Kotlin e Spring Boot, simulando uma aplicação de vendas de livros.

## Tecnologias utilizadas

- Kotlin
- Spring Boot
- Gradle
- H2 Database

## Observações

Este projeto está em fase inicial e serve para fins de aprendizado e experimentação.
